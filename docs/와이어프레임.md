## 0. 기술 구성 (Vercel 배포)

| 영역 | 선택 | 이유 |
| --- | --- | --- |
| 프레임워크 | **Next.js 15 (App Router, TypeScript)** | Vercel 네이티브. 프론트+API(서버리스)를 한 프로젝트로 |
| 스타일 | **Tailwind CSS** | 반응형·유지보수 용이 |
| 폼 백엔드 | **Route Handler `/api/*`** (또는 Server Actions) | 고객문의·견적문의 접수 |
| DB | **Vercel Postgres(Neon)** + Prisma | 문의·견적 접수 저장, 관리자 조회 |
| 파일 업로드 | **Vercel Blob** | 견적문의 첨부파일 (서버리스라 로컬 저장 불가) |
| 메일 알림 | **Resend** | 접수 시 `gigatech23@daum.net`로 알림 |
| 관리자 | `/admin` + 비밀번호(환경변수) 또는 NextAuth | 접수 목록·첨부 다운로드 |
| 도메인/HTTPS | Vercel Custom Domain `gigatech.kr` | SSL 자동 적용(요청사항 충족) |
| 지도/채널 | 카카오 채널 링크(외부), (선택)카카오맵 | `pf.kakao.com/_jCNyxj` |

**라우트 맵**
```
/                         홈
/about/greeting           회사소개 > 인사말
/about/organization       회사소개 > 조직도
/about/certificate        회사소개 > 인증서
/business/overview        주요업무 > 기계설비 개요
/business/obligations     주요업무 > 관리주체의 의무사항
/business/performance     주요업무 > 기계설비 성능점검
/business/maintenance     주요업무 > 기계설비 유지관리점검
/equipment                장비보유현황 > 점검장비
/contact/customer         문의 > 고객문의   (POST /api/inquiry)
/contact/quote            문의 > 견적문의   (POST /api/quote, 첨부)
(카카오채널)               문의 > 외부 링크
/admin                    관리자(접수 조회)
```

**DB 스키마(초안)**
```
Inquiry(고객문의)  id, company, name, phone, email, replyMethod(전화|이메일|방문),
                   title, content, agreed, createdAt
Quote(견적문의)    id, building, manager, phone, email, address,
                   targetFacilities(string[]), request, fileUrl?, agreed, createdAt
```

## 8. 반응형 원칙
- 브레이크포인트: 모바일 <768 / 태블릿 768~1024 / 데스크톱 >1024
- 카드 그리드: 데스크톱 4열 → 태블릿 2열 → 모바일 1열
- 표(의무사항 선임기준 등): 모바일에서 가로 스크롤 또는 카드형 전환
- 이미지 캡처 자료는 본문 텍스트를 1차, 이미지를 보조로(접근성·SEO)
