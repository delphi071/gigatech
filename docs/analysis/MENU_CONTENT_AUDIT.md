# 홈페이지 메뉴·콘텐츠 자료 분석

작성일: 2026-09-26 / 담당: menu_content / 범위: 자료 분석. 제품 구현·게시·배포는 수행하지 않았다.

사용자가 지정한 `페이지 메뉴 구성안.xlsx`의 실제 메뉴는 **대메뉴 3개, 하위 메뉴 5개**다. `디자인중.xlsx`에는 대메뉴 6개, 하위 항목 13개가 있으나 별도 확장안으로 분리해야 한다. 기준안의 **정보통신설비 성능점검**은 별도 확장안에 없으며, 제공 자료에서도 전용 본문·사진을 찾지 못했다.

## 1. 출처와 적용 우선순위

아래 경로의 기준 폴더는 `docs/1.홈페이지 제작관련/`이다. 엑셀 셀 주소는 병합 영역 좌상단을 뜻한다. 파일의 저장일은 문서의 승인·업무 적용일을 증명하지 않는다.

| ID | 원본 | 적용 |
| --- | --- | --- |
| M | `페이지 메뉴 구성안.xlsx` / `페이지 메뉴 구성안 (국문)` | 사용자가 지정한 메뉴 기준. 3대메뉴·5하위 항목 |
| D | `디자인중.xlsx` / `페이지 메뉴 구성안 (국문)` | 별도 확장안 및 본문 요구 참고. 자동 채택하지 않음 |
| X | `(예시) 페이지 메뉴 구성안 (예시).xlsx` | 작성 방식 설명용. 회사 메뉴·콘텐츠 요구에 합산하지 않음 |

| T2 | `내부내용자료/인사말.txt` | 회사 소개 원고 |
| T3 | `홈페이지 수정자료/요청사항.txt` | 로고·이메일·개인정보 담당자·카카오 링크·SSL 요청 기록 |
| T4 | `홈페이지.txt` | 도메인 `gigatech.kr` 기록. 현재 운영 상태를 증명하지 않음 |

XLSX 내부 `docProps/core.xml` 수정 메타데이터: M `2026-08-24T00:30:18.055`, D `2023-05-24T00:42:31Z`, X `2023-05-16T06:00:56Z`. M은 시간대 표기가 없다. 메타데이터는 저장 흔적으로만 사용하며, 기준 선택의 직접 근거는 사용자 지정이다.

원본 M의 값이 있는 셀 14개를 모두 대조했다. 그 외 셀은 서식·빈칸이며 추가 메뉴로 계산하지 않았다.

기계설비개요 폴더의 사진 유형은 공기조화, 급수·급탕, 덕트, 방음·방진·내진, 배관, 보온, 열원·냉난방, 오·배수·통기·우수배수, 오수정화·물재이용, 위생기구, 자동제어, 환기다. 건축물 수명연장·에너지절약·전문적인 기계설비·쾌적하고 안전한 생활환경 이미지도 있다. 이 파일명만으로 기가테크가 모든 설비의 서비스를 제공한다고 주장하지 않는다.

자산 담당의 실제 열람에서 `기계설비란.PNG`는 소개 문단 중복 및 출처 없는 연간 에너지 비용 11% 절감 수치를 포함했다. 중복은 제거하고, 절감 수치는 근거 확보 전 자사 홍보문구에 넣지 않는다. 조직도는 두 파일의 부서 구조가 다르고 CONTOSO 템플릿 흔적이 있어 현재 조직 확인 후 다시 제작해야 한다.

`추가발송본/기계설비 성능점검 대상 이미지.zip`은 명칭과 달리 실제 이미지 중복 관계를 자산 보고서에서 확인해야 하며, 새 대상 기준표가 있다고 간주하지 않는다. ZIP 파일 수를 콘텐츠 수로 중복 계산하지 않는다.

5. 공통 회사정보·브랜드 로고·외부 채널은 원본 기록과 현재 사실을 대조한다. 본 분석 결과만으로 게시 승인 완료로 보지 않는다.
