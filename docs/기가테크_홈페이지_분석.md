## 3. 확정 메뉴 구조 (2026-09-26 사용자 확정)

사용자 결정에 따라 **대메뉴 4개**로 확정. 정보통신설비 성능점검·기계설비법 독립메뉴는 제외.

```
홈 (메인)
├─ 회사소개
│   ├─ 인사말            ← 인사말.txt 확보
│   ├─ 조직도            ← 조직도_회사명제거.pptx (CONTOSO 삭제 완료)
│   └─ 인증서            ← 원본 없음(추후 자료 수령)
├─ 주요업무
│   ├─ 기계설비 개요       ← 기계설비란/범위 + 설비 12종
│   ├─ 관리주체의 의무사항  ← 기술·유지관리기준 준수 / 법위반 행정조치
│   ├─ 기계설비 성능점검    ← 검토사항 / 대행절차 / 결과보고서 대행
│   └─ 기계설비 유지관리점검 ← 월1회 현장 월점검 / 유지관리자 결과보고서 대행
├─ 장비보유현황
│   └─ 점검장비           ← 장비사진.png/2.png (측정기 20종)
└─ 문의
    ├─ 고객문의           ← 고객요청양식.PNG 폼
    ├─ 견적문의           ← 견적요청양식.PNG 폼
    └─ 카카오채널          ← pf.kakao.com/_jCNyxj (채팅: /chat)
```

> 기존 (A)간략본·(B)디자인중·(C)변동요청 간 충돌이 있었으나, 위 4개 대메뉴 구조로 정리됨.
> `기계설비법`(개요·의무사항)은 별도 대메뉴 대신 **주요업무 하위**로 흡수.
> 카카오톡/온라인채팅은 **문의 > 카카오채널** 한 항목으로 통합(같은 채널 URL).
